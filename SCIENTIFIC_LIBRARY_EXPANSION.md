# Four-discipline scientific Library expansion

The existing original-preserving scientific-pack and Library systems are reused. Approved scientific editions with exactly one supported collection marker appear in Mathematics, Physics, Chemistry, Engineering, or Materials Science. Unknown or ambiguous markers remain in Science. Derived pages and rights artifacts are never promoted into complete-book destinations. Existing Books, Science, Projects, History and Chat are preserved.

No database migration, model configuration change, network permission, or new reader dependency is introduced. Imports require independently reviewed edition rights, exact original SHA-256 identities, approved local packs, bounded page-linked extraction and existing explicit approval controls. Third-party exceptions are screened separately; a publisher-level CC notice is not blanket permission.

The external acquisition operator remains separate from VECTOR and has no application, model, data or owner-home mounts. Extraction remains network-denied with namespaces, seccomp and verified cgroup memory/process/CPU limits.
