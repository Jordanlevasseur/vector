# Normal Chat and the offline Library

The saved 2B refusal completed real inference with an empty source list. The
normal native Chat route supplied generic instructions and history, whereas
retrieval lived in separate evidence/semantic routes. No evidence established a
filesystem denial or a prompt instruction requiring that refusal.

Native Chat now prepares bounded Library evidence before selecting/invoking a
model. It uses existing literary FTS, registered scientific extracted pages,
registered title/author metadata, bounded owner-imported original text notes, and the existing safety-aware botanical
context builder. Ordinary greetings, self-contained premise analysis, creative requests and checked literal arithmetic skip lookup unless an explicit Library request applies. Explicit find/show-source commands retain their existing source-only behavior.
Quoted title scopes never fall back to another book. Short follow-ups can reuse
the previous question; generated prior answers are never retrieval evidence.

S labels identify exact frozen original event/hash/character windows. C labels
identify durable edition metadata and cannot establish book content. The model
gets compact labels and text; the host retains provenance. The unchanged strict
citation validator resolves S labels. Valid markers prove provenance, not
semantic entailment, clinical correctness or source agreement. Missing/invalid
labels or a no-match lookup prevent presentation as a grounded answer while
retaining genuine raw inference and allowing subsequent manual operation.

Library-assisted native prompts use a versioned evidence contract (instruction3,
validation4). Requests needing no retrieval retain the original compact native framing and validation3. Existing saved prompt versions and validators remain supported.
Both mode receives the same evidence in independent calls and all peer stages.
The isolated worker records a SHA-256 of the actual message payload submitted
to its local inference endpoint. Request-scoped context growth passes existing
qualification, memory enforcement and prompt bounds; no preference or resource
consent is silently changed. Complete evidence and peer handoffs are rejected
if they do not fit, never silently shortened.

Botanical taxonomy, preparations, formulas and practices remain separate
concepts. Every matched subject's mandatory negative/safety evidence is retained;
classifications pin actual durable record revisions. New/resumed generation
checks current source approval. Historical replay retains its original version.
Multiple/large subjects may require a narrower request rather than selective
medical evidence. No facts, assets or training data are acquired here.

Lookup is bounded (30-second SQLite instruction deadline, four query variants,
four excerpt windows or up to eight essential botanical windows). Disk I/O can
delay cancellation until the kernel returns. A query never loads all passages,
rebuilds an index or changes the bookshelf paging snapshot. Index failures,
timeouts, permissions, missing originals, context limits and inference failures
retain distinct diagnostics and the durable question.

Limitations: literal retrieval is not semantic search; recall and excerpt
selection can fail. Catalogue metadata currently covers registered scientific
and literary editions; large standalone attachments and authored manuals remain
available in Library but are not automatically indexed by this Chat route. Small existing original text notes use the same authorized retrieval API, with a 256 KiB bound.
Whole-book summaries are not inferred from snippets. Existing complete-body
summary acceptance and routing remain intact for explicit whole-document summaries.
No output is promoted to verified knowledge or a release qualification.
