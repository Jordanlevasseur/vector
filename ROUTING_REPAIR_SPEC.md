# Ordinary conversation capability routing

The default Desktop Send → Application.ask boundary recognizes the complete
operation before invoking retrieval or preparing a model. This is a bounded
language frontend over existing tools, not a general semantic-understanding claim.
The original experimental planner and connected-evidence controls remain opt-in;
their historical v1 interpretation/replay is unchanged.

## Calculator and checked results

A fully consumed numeric grammar normalizes explicit natural-language operators,
Unicode multiplication/division, precedence, parentheses, scientific notation,
unambiguous grouped numbers, percent-of, bounded integer powers and the existing
unit-conversion operation. No eval, Python calls, attributes, model-issued tools or
shell execution is permitted. Unknown syntax, mixed objectives, ambiguous grouping,
compound postfix percentages, unsupported functions and implicit multiplication
receive clarification or the existing tool's truthful failure. No partial result
is accepted as completion of a mixed request.

Execution uses existing Decimal/SI tools and durable Investigations with calculate
steps and compose. Simple arithmetic has one calculation and one checked composition;
there is no exploratory plan or neural call. Ordered operations use existing
checked dependency bindings. Existing expression, precision, unit, exponent,
time and step budgets remain authoritative. Unit-bearing continuations require
an explicit quantity method rather than silently discarding units.

Conversation input and its stable investigation identity are persisted before
execution. Retry of the same request identity recovers interrupted work, compares
the original objective and operations, and reconstructs completed answers without
executing a duplicate task. Explicit cancellation is respected. The saved reference
contains immutable answer-event IDs, never a cached certified result. History and
portable restoration independently replay the original calculation and compare its
question, project, plan and premises. A follow-up may use only the immediately
preceding checked numeric answer from the same conversation/project. Source/model
prose is never a numeric premise. Derived checked views cannot be imported as truth.

## Sources and generation

Explicit finding/searching requests use the subject rather than operation words
or unrelated prior questions. Bounded all-term passage selection and literal phrase
preference improve relevance; this is not semantic relevance certification. Ordinary
library/search APIs retain their previous defaults. Literary heading filtering and
archived-title body selection avoid substituting a document title or front matter
for content. Original bytes, indexes, provenance, rights records and notices remain
unchanged. Rights notices remain inspectable in the response/evidence view and
original-source view, after a visible notice directs the reader there.

Retrieved text is labeled source material, never an automatically completed
explanation or summary. Missing evidence is reported. Conflicting sources and
scoped assumptions remain visible and do not become checked conclusions.

Summarization is an explicit operation. Without a qualified model/method it returns
a clear limitation and offers original body excerpts. Multiple matching works do
not qualify as an unambiguous complete summary target. A model summary is attempted
only with a complete identified body inside the existing conservative prompt budget;
essential source text is not silently clipped. Strict JSON and original citation
checks remain in force. A quotation alone is not a summary. Model synthesis remains
an unverified draft; citation fidelity does not establish semantic correctness.

Unfamiliar questions preserve the full objective. A qualified existing neural
adapter can still serve the established inference path; unavailable interpretation
gets an honest limitation and a reference to the existing explicit Plan and
investigate control. There is no automatic experimental planning, model selection,
model loading for arithmetic/search, default-model change or simulated production
fallback. Open-ended creativity and general reasoning are not newly qualified here.

## Desktop and verification

The approved native theme, core, navigation, fixed composer and bubble-free stream
remain. Default answers, checked values, source links and limitations are rendered
through the actual Desktop.answer path and saved history. Advanced inspection shows
full provenance and proof records. Old conversation payloads are not rewritten.

Required checks: independent arithmetic gold; no model/retrieval for arithmetic;
unknown/ambiguous/mixed inputs; source relevance and late passages; contradictions;
summary schema/fidelity/budget failures; repeated IDs; continuations/project scope;
interruption and cancellation; history/restart/import tampering; actual protected
GUI Send/history; original 52 checked-answer cases; source and installed suites;
full database/original integrity and unchanged laws/models/corpora/backups.

No schema migration, dependency, new core engine or network permission is added.
