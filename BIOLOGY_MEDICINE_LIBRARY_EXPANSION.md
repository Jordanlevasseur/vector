# Biology and Medicine & Anatomy Library expansion

The existing original-resource catalogue recognizes the unambiguous collection tags
`collection:Biology` and `collection:Medicine & Anatomy`, alongside the five existing
scientific collections. Derived passages and rights receipts do not become complete
books. Conflicting collection tags retain the generic Science category.

No database migration, new index, inference change, network permission, or external
reader is introduced. The existing scientific-pack importer remains responsible for
complete-original hashes, edition-specific rights evidence, bounded extraction,
provenance and source-linked search. Each medical edition must retain a publication
date and the existing `historical` or `dated-reference-not-current-guidance` status.
A recent publication date alone does not certify current clinical guidance.

The owner-directed acquisition target is 20 Biology and 20 Medicine & Anatomy
complete works, each counted once in a primary subtopic. Counts, rights decisions,
reader acceptance, integrity and installed tests are evidence recorded separately in
`outputs/vector-biology-medicine-expansion-20261105` in the Codex workspace. Category
support does not itself establish that any acquisition quota has been met.

Validation: complete source regression and actual-host Library/reader isolation tests
are required; installation is bound to the built module hashes. Retain the matching
baseline wheel, database snapshot and independently verified original-object copy for
rollback. No pre-existing resource, model, memory, conversation or original is replaced.
