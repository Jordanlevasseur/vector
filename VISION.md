# VECTOR vision
Build a durable, efficient, evidence-aware offline personal intelligence system.
The J.A.R.V.I.S. comparison is a long-term usefulness target, not consciousness,
fictional capabilities or demonstrated intelligence. Preserve all intentionally
submitted originals, provenance, disagreement and user authority. Memory is not
model weights. Models and hardware must remain replaceable. VECTOR is independent
of HELIX and Stage 9 integration is not authorized.

[FOUNDATIONAL_LAWS.md](FOUNDATIONAL_LAWS.md) V1.0 defines the authoritative
owner requirements for open-ended independent discovery and final authenticated
owner decision authority. Intellectual independence includes honest disagreement;
owner control governs discretionary decisions without falsifying evidence or
silently removing technical/security boundaries. These are architectural goals,
not claims of implemented discovery or authenticated override capability.
